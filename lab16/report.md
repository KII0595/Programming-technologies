## Цель работы

Освоить на практике использование российской языковой модели GigaChat для решения типовых задач разработки: генерацию кода по описанию, улучшение (рефакторинг) существующего кода, генерацию тестов и документации.

## 1. Настройка и реализация клиента

Для работы с API был создан модуль `ai_assistant/client.py`. Он отвечает за:
- загрузку настроек из `.env`
- инициализацию клиента GigaChat
- удобную отправку промптов
- очистку markdown-обрамления из ответов модели
- обработку возможных ошибок

Использовалась библиотека `gigachat` + `python-dotenv`.

Ключевые особенности реализации:
- Вынос общих настроек в отдельный `utils.py`
- Поддержка разных моделей (GigaChat-2, Pro и т.д.)
- Автоматическая очистка кода из ответа модели

---

## 2. Генерация кода

С помощью GigaChat были сгенерированы три функции (файл `generated.py`):

1. **Валидация email-адреса** (с использованием `re` + проверка длины домена)
2. **Сортировка списка словарей** по произвольному ключу
3. **Декоратор** для замера времени выполнения функций

Модель хорошо справилась с типизацией и добавлением docstring'ов.

---

## 3. Рефакторинг "плохого" кода

Был взят плохо написанный код (`legacy_code.py`) со следующими проблемами:
- неинформативные имена переменных и функций
- отсутствие type hints
- глобальные переменные
- слабая обработка ошибок
- отсутствие документации

После запроса на рефакторинг модель выдала значительно улучшенную версию (`improved_code.py`):
- говорящие названия
- полные аннотации типов
- docstring'и в стиле Google
- константы вместо глобальных переменных
- улучшенная обработка исключений

## 5. Выводы и ответы на вопросы
**Какие задачи лучше всего решаются GigaChat?**
Отлично справляется с шаблонным кодом, рефакторингом, написанием тестов и документации. Хуже — со сложной бизнес-логикой и архитектурными решениями.

**Были ли ошибки в сгенерированном коде?**

Да, иногда:
- Не всегда правильно обрабатывались edge-кейсы
- Мог использовать устаревшие подходы
- Иногда добавлял лишние зависимости

Все критические ошибки были исправлены вручную.

**Отличие от использования сниппетов?**

ИИ генерирует код под конкретную задачу с учётом контекста, а не просто вставляет шаблон.
Риски использования ИИ:

- Галлюцинации и скрытые баги
- Зависимость от качества промпта
- Возможные проблемы с безопасностью (если не проверять)
- Нарушение авторских прав (в теории)

**Сравнение с ChatGPT:**

GigaChat чуть хуже понимает сложные инструкции, но лучше работает с русским языком и иногда даёт более "аккуратный" код.
